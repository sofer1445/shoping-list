# Product

<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
Hebrew-speaking households planning shared shopping and buying groceries in stores on narrow mobile screens.

## Product Purpose
Manage household shopping from planning through purchasing and repeat buying. The current redesign prioritizes clarity and comfort in the store, as confirmed by the user.

## Operating Context
Lists support planning; Shopping supports execution; History supports repeat buying; Insights supports decisions. A dedicated full-screen focus view supplements the existing dense list view.

## Capabilities and Constraints
Preserve existing list management, sharing, realtime presence, progress, remaining-item export, history, analytics and authentication. Hebrew-only RTL UI, mobile-first, with Capacitor packaging support. This request changes presentation, not data or permissions.

## Brand Commitments
Existing product name: סל קניות. Existing brief specifies a calm Cloud White base, Sora and Manrope typography, and feed-style lists.

## Evidence on Hand
Existing application code and product icons; live private records cannot be verified using managed authentication because this project uses an external Supabase connection. Do not invent household records or shopping statistics.

## Product Principles
- Product recognition and the next shopping action take precedence over decorative UI.
- Preserve the distinction between planning and focused execution.
- Shared and private data retain existing access boundaries.
- Make touch actions comfortable and labels clear on narrow screens.
